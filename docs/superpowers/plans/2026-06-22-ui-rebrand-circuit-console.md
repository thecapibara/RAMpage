# UI Rebrand — Circuit-Board Console Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the RAMEATER dashboard (and its confirm modal) from a rainbow/glow/graffiti "AI slop" look into a single-theme circuit-board console that matches the app's brand icon — black field, electric green `#00FF66` accent, cyan `#00FFFF` = active/feeding, red `#ff3a3a` = destructive — with zero logic, state, or layout changes.

**Architecture:** Pure visual-layer rewrite. Every change is a `className` string swap, a removal of the inline `<style>` font import, or an inline-derived presentation value (the status LED). No new components, no new dependencies, no state variables, no effects. The status LED is computed inline in `Dashboard.jsx`'s render from existing boolean state. Tailwind theme is not extended in v1 — literal hex values in arbitrary-value classes (`bg-[#00FF66]`, `border-[#1a261a]`, etc.) keep the diff localized and the tokens obvious.

**Tech Stack:** React 19, Tailwind CSS 3 (via arbitrary-value classes, no config change), Vite 5.

**Spec:** `docs/superpowers/specs/2026-06-22-ui-rebrand-circuit-console-design.md`

**Verification note — there is NO test runner in this project** (`package.json` has no `test` script, no vitest/jest installed). This plan uses `npm run build` + `npm run lint` + manual visual inspection as verification gates, not unit tests. Do not invent a test framework.

```jsx
  const anyActive = isAllocating || isFillingStorage || gpuActive || netActive ||
                    vramActive || isBenchmarking || gpuBenchMode !== 'NONE';
```
